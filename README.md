# 🕷 Спайдер-чекер

Телеграм-бот, который следит за афишей двух кинотеатров и сообщает, как только
там появится «Человек-Паук: Новый день» — даже если в российском прокате фильм
назовут иначе.

Отслеживаемые площадки:
- [kino-vershina.ru](https://kino-vershina.ru/) — «Вершина»
- [drugar.ru](https://drugar.ru/) — «Другар»

## Как это работает

Оба сайта сделаны на одной платформе (`p24.app`, Next.js). Вся афиша приезжает
сервером внутри RSC-пейлоада готовым JSON-ом, поэтому бот парсит **данные**, а
не HTML-вёрстку: из карточки доступны название, статус проката, количество
сеансов, даты, цены, жанр, страна, режиссёр, актёры и описание. Такой парсер не
ломается от редизайна.

Каждые 10 минут (настраивается) бот забирает афишу, сравнивает со слепком из
`data/state.json` и шлёт уведомление. **Бот следит за одним фильмом** — про
посторонние картины в чат не пишет:

| Событие | Когда срабатывает |
|---|---|
| 🎟🚨 Билеты в продаже | у цели появились сеансы — главный сигнал, со списком времён, залов и цен |
| ➕ Добавили сеансы | к уже известным сеансам цели добавились новые |
| 🕷 Похожий фильм в афише | появился фильм, похожий на цель, ещё без билетов |
| ✏️ Переименование / смена статуса | у цели сменилось название или «скоро» → «в прокате» |
| 🕸 Упоминание вне афиши | «паук» и «новый день» встретились рядом где-то на странице (баннер, новость) |
| 🎬 Тихая строчка | в афише появились посторонние новинки — одним сообщением, без звука |

Последний пункт — страховка на случай, если название замаскируют до
неузнаваемости: карточками они чат не забивают, но вы увидите, что появилось
что-то новое. Отключается через `NEW_FILM_DIGEST=0`.

Когда цель найдена в афише, бот сам переходит на проверку раз в 2 минуты —
билеты разбирают быстро.

## Алгоритм распознавания

Название заранее неизвестно, поэтому решение принимается по сумме признаков, а
не по одной строке:

- «паук» / `spider` / «Новый день» / `brand new day` в названии или описании;
- ключевые люди фильма: Том Холланд, Дестин Дэниел Креттон;
- второй состав: Зендея, Джейкоб Баталон, Сэди Синк, Марк Руффало, Кевин Файги…;
- маркеры вселенной: Питер Паркер, Marvel, Sony Pictures;
- ваши собственные ключевые слова (`/watch`).

Итог — уровень уверенности:

- **high** 🕷🚨 — громкий алерт «похоже, это он»;
- **medium** 🕷 — уведомление с кнопками ручной проверки;
- **low** ❓ — только в `/candidates`, чат не беспокоит;
- **none** — не он.

**Главное правило — приметы франшизы обязательны.** Если в карточке нет ни
«паука»/«паутины», ни «Нового дня», ни Питера Паркера / Marvel / Sony, ни
режиссёра Креттона — фильм отбрасывается сразу, сколько бы знакомых актёров
в нём ни снималось. Без этого правила в кандидаты лезла «Одиссея» Нолана: там
те же Том Холланд и Зендея. Один только состав ничего не доказывает.

Ретро-показы тоже учтены: кинотеатры регулярно ставят старые части («Нет пути
домой», «Через вселенные» и т. д.) — известные прошлые фильмы понижаются до
`low` и чат не беспокоят.

Окончательное слово всегда за человеком — под каждой карточкой кнопки
**✅ Это Паук**, **❌ Не он**, **🔕 Больше не писать про него**.

## Запуск

```bash
pip3 install -r requirements.txt      # нужен только requests
cp .env.example .env                  # вписать токен от @BotFather
python3 run.py
```

Затем в Telegram — `/start`.

Проверить парсер и алгоритм без Telegram:

```bash
python3 selftest.py
```

## Команды

| Команда | Что делает |
|---|---|
| `/check` | проверить оба сайта прямо сейчас — ответит, есть Паук или нет |
| `/candidates` | карточки совпадений с оценкой алгоритма |
| `/list` | вся афиша целиком, если захочется посмотреть глазами |
| `/watch слово` | добавить своё ключевое слово |
| `/unwatch слово` | убрать ключевое слово |
| `/keywords` | список своих ключевых слов |
| `/unmute` | сбросить все ручные вердикты и мьюты |
| `/status` | статистика и время последней проверки |
| `/stop` | отписаться |

Под полем ввода — две кнопки: 🕷 Проверить Паука и ⚙️ Статус.

## Настройки (`.env`)

| Переменная | По умолчанию | Значение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | токен от @BotFather |
| `CHECK_INTERVAL` | `600` | интервал проверки, секунд |
| `CHECK_INTERVAL_HOT` | `120` | интервал, когда цель уже в афише |
| `NEW_FILM_DIGEST` | `1` | тихая строчка про посторонние новинки (`0` — молчать) |
| `HTTP_TIMEOUT` | `30` | таймаут запроса к сайтам |
| `ADMIN_CHAT_ID` | `0` | кому слать техошибки (0 — всем подписчикам) |

## Чтобы работал постоянно

Бот должен быть запущен — иначе проверок не будет. Простой вариант на macOS:

```bash
nohup python3 run.py > /dev/null 2>&1 &   # лог сам пишется в data/bot.log
tail -f data/bot.log                       # смотреть, что происходит
pkill -f run.py                            # остановить
```

Экземпляр должен быть ровно один: два параллельно запущенных бота отбирают
друг у друга подключение и в логе появляется `Conflict: terminated by other
getUpdates request`. Проверить — `pgrep -af run.py`.

Надёжнее — автозапуск через launchd, шаблон лежит в
`deploy/launchd.plist.example` (замените пути, положите в
`~/Library/LaunchAgents/`, затем `launchctl load ...`).

## Структура

```
run.py               точка входа
selftest.py          проверка парсера и алгоритма без Telegram
config.py            настройки и список площадок
src/parser.py        разбор RSC-пейлоада p24.app → объекты Film
src/matcher.py       распознавание «Человека-Паука»
src/checker.py       сравнение со слепком, сбор алертов
src/notifier.py      тексты уведомлений и клавиатуры
src/telegram_api.py  клиент Bot API на requests
src/bot.py           команды, кнопки, фоновый цикл
data/state.json      состояние (в git не попадает)
```

## Если сайт переедет

Парсер сам заметит, что в пейлоаде нет фильмов, и пришлёт предупреждение
вместо тихого молчания. Добавить третий кинотеатр на той же платформе — это
одна запись в `SITES` в `config.py`.
